# ocaml/golden

The root of this directory holds the IR goldens: each `*.camdl` with its
committed `*.ir.json`, regenerated by `make update-ocaml-golden` and reviewed by
a person on every change. Each one is also simulated by
`tests/test_ocaml_to_rust.sh`, schema-checked by
`rust/crates/ir/tests/schema_validates_goldens.rs`, used as a sample model by
Rust tests, and required to compile without errors or warnings by
`test_corpus_clean` in `ocaml/test/test_diagnostics.ml`.

Each subdirectory is named for its role:

- `data/` holds input files the goldens read.
- `diagnostics/` holds models whose claim is the set of diagnostics the compiler
  emits, not their IR. Each is one minimal model testing one rule and opens with
  three required lines:

  ```camdl
  # invariant: a transfer `fraction` is dimensionless
  # spec: §5.1, position "transfer fraction"
  # expect: E314 Error
  ```

  `# expect: (none)` asserts that a model compiles with no diagnostic at all,
  Info included. The driver is the fixture test in
  `ocaml/test/test_diagnostics.ml`; it discovers files recursively and refuses a
  file missing any of the three lines. The directories under `diagnostics/` name
  the area of the language under test (`dimcheck/<area>/`, `lints/`,
  `semantic/`), and valid and invalid models of one rule sit side by side.
  `make diagnostics-invariants` lists what each area already covers; read it
  before adding a model.

`§` references in `# spec:` lines without a document name are to
`docs/dev/proposals/2026-11-06-dimension-checking-as-one-constraint-system.md`
until the language spec states those rules; `warning-catalog` is
`docs/dev/warning-catalog.md`.
